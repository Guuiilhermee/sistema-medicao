Projeto de sistema de medição de grandezas físicas é o desenvolvimento de uma solução capaz de coletar e registrar valores como temperatura, pressão ou frequência cardíaca, permitindo o monitoramento e a análise desses dados para diferentes aplicações. Como um Escalímetro
